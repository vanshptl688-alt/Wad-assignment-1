## GitHub Pages Hosting
1. Create a new GitHub repository, for example `arvind-krishna-profile`.
2. Upload `index.html`, `style.css` and `README.md`.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select `main` and `/ (root)`, then click **Save**.
7. GitHub will provide the Pages URL, usually:
   `https://YOUR-USERNAME.github.io/arvind-krishna-profile/`
